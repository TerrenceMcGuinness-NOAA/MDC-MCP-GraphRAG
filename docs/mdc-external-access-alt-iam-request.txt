ITEM 8 — GATEWAY EXECUTION ROLE (NOT YET CREATED)
======================================================================

Role:   mdc-mcp-alt-gateway-exec-role
Status: NOT YET CREATED
Spec:   .kiro/specs/mcp-external-access-alternative-gateway/ (Task 2.3)

Purpose: AgentCore Gateway assumes this role to sign SigV4 outbound
requests to the Runtime target (design AD-C6, R1.3, R2.5).

  Trust policy:

    {
      "Version": "2012-10-17",
      "Statement": [{
        "Effect": "Allow",
        "Principal": { "Service": "bedrock-agentcore.amazonaws.com" },
        "Action": "sts:AssumeRole",
        "Condition": {
          "StringEquals": {
            "aws:SourceAccount": "903050880929"
          },
          "ArnLike": {
            "aws:SourceArn": "arn:aws:bedrock-agentcore:us-east-1:903050880929:gateway/*"
          }
        }
      }]
    }

  NOTE: aws:SourceArn uses a gateway/* wildcard because the Gateway ARN
  is not known until the first cdk deploy creates the Gateway custom
  resource (Task 2.2). After creation, tighten to the exact Gateway ARN.
  aws:SourceAccount is always exact. These conditions prevent confused-
  deputy attacks (AD-C6, DP-4).

  Permissions (inline policy: invoke-runtime-target):

    {
      "Version": "2012-10-17",
      "Statement": [{
        "Sid": "InvokeRuntimeTarget",
        "Effect": "Allow",
        "Action": "bedrock-agentcore:InvokeAgentRuntime",
        "Resource": "arn:aws:bedrock-agentcore:us-east-1:903050880929:runtime/mdc_mcp_rag_server_python-v5K2F8BGrN*"
      }]
    }

  NOTE: Trailing * on the Resource ARN covers both the bare runtime ARN
  and the /runtime-endpoint/DEFAULT sub-resource path that the Gateway
  evaluates (see Item 3 correction above for precedent).

  Create commands:

    aws iam create-role \
      --role-name mdc-mcp-alt-gateway-exec-role \
      --assume-role-policy-document '{"Version":"2012-10-17","Statement":[{"Effect":"Allow","Principal":{"Service":"bedrock-agentcore.amazonaws.com"},"Action":"sts:AssumeRole","Condition":{"StringEquals":{"aws:SourceAccount":"903050880929"},"ArnLike":{"aws:SourceArn":"arn:aws:bedrock-agentcore:us-east-1:903050880929:gateway/*"}}}]}' \
      --description "AgentCore Gateway execution role for MDC MCP external access (Path C)" \
      --region us-east-1

    aws iam put-role-policy \
      --role-name mdc-mcp-alt-gateway-exec-role \
      --policy-name invoke-runtime-target \
      --policy-document '{"Version":"2012-10-17","Statement":[{"Sid":"InvokeRuntimeTarget","Effect":"Allow","Action":"bedrock-agentcore:InvokeAgentRuntime","Resource":"arn:aws:bedrock-agentcore:us-east-1:903050880929:runtime/mdc_mcp_rag_server_python-v5K2F8BGrN*"}]}'

  Verify:

    aws iam get-role --role-name mdc-mcp-alt-gateway-exec-role \
      --query 'Role.{Name:RoleName,Created:CreateDate}' --output table

  Trust policy:

    {
      "Version": "2012-10-17",
      "Statement": [{
        "Effect": "Allow",
        "Principal": { "Service": "lambda.amazonaws.com" },
        "Action": "sts:AssumeRole"
      }]
    }

  Permissions:
    - Managed: arn:aws:iam::aws:policy/service-role/AWSLambdaBasicExecutionRole
      (CloudWatch Logs create/put)

  request headers and injects trusted-context headers. It does not
  access Neptune, OpenSearch, Bedrock, Secrets Manager, or any other
  AWS service.

  Create commands:

    aws iam create-role \
      --role-name mdc-mcp-alt-interceptor-role \
      --assume-role-policy-document '{"Version":"2012-10-17","Statement":[{"Effect":"Allow","Principal":{"Service":"lambda.amazonaws.com"},"Action":"sts:AssumeRole"}]}' \
