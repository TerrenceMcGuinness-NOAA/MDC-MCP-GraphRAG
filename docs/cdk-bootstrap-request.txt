REQUEST
-------

Please run the AWS CDK bootstrap command for account 903050880929 in
us-east-1. This is a one-time setup that creates the IAM roles and S3
bucket that CDK needs to deploy CloudFormation stacks. It does NOT
create any services, endpoints, or internet-facing resources.


STEP 1 — Delete failed stack (required)

A previous bootstrap attempt left a CDKToolkit stack in
ROLLBACK_COMPLETE state. Please delete it first:

    aws cloudformation delete-stack --stack-name CDKToolkit --region us-east-1


STEP 2 — Run bootstrap

    cdk bootstrap aws://903050880929/us-east-1

If CDK CLI is not installed, it can be run via npx:

    npx aws-cdk bootstrap aws://903050880929/us-east-1


WHY THIS REQUIRES ADMIN
-----------------------

CDK bootstrap creates 4 IAM roles at the account root path. The
PowerUser group policy does not allow iam:CreateRole outside of
service-role/* and aws-service-role/* paths.

Roles CDK needs to create:

  1. cdk-hnb659fds-cfn-exec-role-903050880929-us-east-1
     Purpose: CloudFormation execution role

  2. cdk-hnb659fds-lookup-role-903050880929-us-east-1
     Purpose: Resource lookups during synthesis

  3. cdk-hnb659fds-image-publishing-role-903050880929-us-east-1
     Purpose: ECR image publishing

  4. cdk-hnb659fds-file-publishing-role-903050880929-us-east-1
     Purpose: S3 asset publishing

It also creates one S3 bucket for CloudFormation template staging:
  cdk-hnb659fds-assets-903050880929-us-east-1


WHAT THIS ENABLES (internal only — no internet-facing resources)
----------------------------------------------------------------

Once bootstrapped, the PowerUser account can deploy internal-only
CDK stacks within the existing VPC for:

  - Amazon Neptune (graph database, private subnets only)
  - Amazon OpenSearch (vector search, private subnets only)
  - Amazon S3 (data migration staging bucket)
  - Amazon EFS (persistent storage)

NOTE: No API Gateway, CloudFront, ALB, or internet-facing endpoints
are included in this phase. Those require a separate escalation and
will be requested later.


WHAT THIS DOES NOT DO
---------------------

  - Does NOT create any internet-facing endpoints
  - Does NOT create any VPC, subnet, or gateway resources
  - Does NOT modify existing network configuration
  - Does NOT expose any services to the internet
  - Does NOT affect other users or workloads in the account


IMPACT
------

  - One-time operation, no recurring maintenance
  - Creates 4 IAM roles + 1 S3 bucket (CDK internal use only)
  - Estimated cost: ~$0.03/month (S3 bucket for CDK assets)
