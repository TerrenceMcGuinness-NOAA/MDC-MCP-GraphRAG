REQUEST
-------

Please attach a new inline policy to an existing IAM role so that the
AgentCore microVM can invoke Anthropic Claude generative models via
Bedrock inference profiles. No new resources are created. The existing
inline policies on this role are not modified.


COMMAND TO RUN
--------------

    aws iam put-role-policy \
      --role-name mdc-mcp-rag-ecs-task-role \
      --policy-name bedrock-invoke-claude-generative \
      --policy-document '{
        "Version": "2012-10-17",
        "Statement": [
          {
            "Sid": "bedrockInvokeGenerativeModels",
            "Effect": "Allow",
            "Action": [
              "bedrock:InvokeModel",
              "bedrock:InvokeModelWithResponseStream"
            ],
            "Resource": [
              "arn:aws:bedrock:us-east-1::foundation-model/anthropic.claude-*",
              "arn:aws:bedrock:us-east-2::foundation-model/anthropic.claude-*",
              "arn:aws:bedrock:*:903050880929:inference-profile/us.anthropic.claude-*"
            ]
          }
        ]
      }' \
      --region us-east-1


VERIFICATION
------------

WHY THIS IS NEEDED
------------------

The AgentCore microVM runs as
arn:aws:sts::903050880929:assumed-role/mdc-mcp-rag-ecs-task-role/...
and currently has bedrock:InvokeModel permission ONLY for Titan
embedding models (arn:aws:bedrock:us-east-1::foundation-model/
amazon.titan-embed-text-*), added May 2026.

Three planned capabilities require generative model access from the
runtime:

1. **Community Summaries Pipeline (Gap J)** — The graph-derived
   community detection pipeline needs ~1,500 LLM calls per tenant to
   generate 4-8 sentence prose descriptions of code subsystems. These
   feed the `search_architecture` and `get_code_context` tools.

2. **EE2 Compliance Analysis** — Future tool enhancement to provide
   LLM-reasoned compliance assessments beyond pattern matching.

3. **Generative MCP Tools** — Any future tool that produces prose
   (code explanations, PR descriptions, incident summaries) rather
   than just retrieving existing content.

All modern Claude models (Opus 5, Opus 4.8, Sonnet 5, etc.) require
invocation via inference profiles (`us.anthropic.claude-*`), which
route across us-east-1 and us-east-2. The resource ARN list covers
both regions and the inference profile namespace.


WHY THIS REQUIRES ADMIN
------------------------

The PowerUser group policy does not allow iam:PutRolePolicy on this
role. Verified August 27, 2026 — same constraint as the May 2026
request.

SECURITY SCOPE
--------------

Two actions. Anthropic Claude model family. Two regions (us-east-1,
