# MCP-RAG Framework

A comprehensive Model Context Protocol (MCP) and Retrieval-Augmented Generation (RAG) framework developed by NOAA EMC/EIB for intelligent workflow assistance and development automation.

## Overview

This framework provides AI-assisted development capabilities for complex systems through:
- **MCP Server Integration** - Model Context Protocol tools and services
- **RAG Knowledge Base** - Vector and graph database semantic search
- **Workflow Intelligence** - Context-aware code analysis and guidance
- **HPC Integration** - High-performance computing platform support

## Architecture

- **`mcp_server_node/`** - Node.js MCP server implementation (v3.0.0)
- **`mcp_server_python/`** - Python MCP server components  
- **`SETUP/`** - Provisioning and deployment configurations
- **`archive/`** - Documentation and legacy components
